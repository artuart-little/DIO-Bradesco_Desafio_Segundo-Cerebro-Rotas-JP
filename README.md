# 🧠 Segundo Cérebro: Otimização de Frotas com RL (João Pessoa)

Este repositório contém a documentação e os materiais de estudo gerados através do **Gemini Notebook (NotebookLM)** para o desafio da DIO. O objetivo é orquestrar um assistente especialista na modelagem de um simulador dinâmico de ônibus para a cidade de João Pessoa (PB).

## 🎯 Escopo do Projeto
A transição de algoritmos estáticos de Pesquisa Operacional para roteamento dinâmico utilizando **Inteligência Artificial (Q-Learning e Processos de Decisão de Markov - MDP)**, visando mitigar o problema estocástico de *bus bunching* (agrupamento de ônibus).

## 📚 Curadoria de Fontes (O "Ouro" Acadêmico)
Para garantir rigor matemático e técnico, o NotebookLM foi alimentado estritamente com **7 fontes de alta credibilidade**, incluindo:
1. Livro base de Reinforcement Learning (Sutton & Barto).
2. Artigos científicos focados exclusivamente em transporte público e estratégias de *holding/stop-skipping*.
3. Diretrizes de comportamento locais (arquivo injetado definindo o contexto de João Pessoa e exigindo paralelos com PO clássica).

## 📁 Materiais Gerados (Disponíveis neste repositório)
A extração de conhecimento foi estruturada em múltiplos formatos através do Estúdio do NotebookLM:

- **`proposta-controle-frota-jp.pdf`**: Relatório técnico definindo formalmente a arquitetura PEAS do agente e a tupla matemática do MDP (Estados, Ações, Recompensa).
- **Áudio (`IA evita ônibus agrupados em João Pessoa.mp3`)**: Podcast sintético discutindo de forma sucinta as estratégias de controle dinâmico em redes de transporte reais.
- **Imagem (`Tráfego Urbano Mapa Mental.png`)**: Estruturação visual comparando a abordagem clássica com a abordagem dinâmica.
- **`Guia_Estudos_Quiz.pdf`**: Material de fixação contendo o quiz de dificuldade avançada gerado pela IA.
